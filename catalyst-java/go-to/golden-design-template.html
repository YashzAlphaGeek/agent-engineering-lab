1. Roleswho does what

BRAIN

The LLM chooses and proposes. It never executes.

VETO

Programmatic gate allows or refuses.

HANDS

The application executes and returns the result.
Prompts steer the LLM. Advisory and probabilistic.
Programmatic logic enforces. Deterministic and cannot be skipped.

4. Human vs agentwho does what

HUMAN

Sets the goal at intake (L0) Writes and reviews the rules before runtime Approves risky steps when a gate asks (L1) Receives the handoff when the agent cannot continue Stays accountable for the outcome

AGENT (LLM plus application)

Plans and proposes the next step Runs the loop and executes allowed actions Reports with sources and structured errors Stops and hands off when blocked or unsure Never changes its own rules
How much human involvement
In the loopapproves each risky step
On the loopmonitors and can stop it
Out of the looponly gates protect, review afterwards
Rule: every GATE is programmatic, so the model cannot skip it.
